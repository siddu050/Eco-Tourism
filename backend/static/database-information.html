Relationships

  • bookings.user_id references users.id
  • bookings.location_id references locations.id
  • favorites.user_id references users.id
  • favorites.location_id references locations.id
  • reviews.user_id references users.id
  • reviews.location_id references locations.id

Role of the Database

The database acts as the central storage layer of the project. It stores user accounts, destination data, trip bookings, saved favorites, and review details. The backend reads and updates this database through SQLAlchemy and FastAPI routes to keep the tourism platform consistent, reliable, and easy to manage.
